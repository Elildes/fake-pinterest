# Fake Pinterest

Este projeto é um site web desenvolvido em Python utilizando o framework Flask. A ideia é criar uma página inicial inspirada no Pinterest, com foco em apresentar uma interface visual de cards e uma experiência mínima de navegação.

## Sobre o projeto

O Fake Pinterest é uma aplicação web básica que demonstra como criar uma página inicial com Flask, renderizando conteúdo diretamente no navegador. O projeto foi pensado como um estudo inicial de desenvolvimento web em Python, mostrando a estrutura de uma aplicação web simples, rotas e execução local.

## Tecnologias utilizadas

- Python
- Flask
- HTML/CSS (em evolução)
- JavaScript (em evolução)

## Como executar

1. Certifique-se de que o Python e o Flask estejam instalados.
2. Abra o terminal na pasta do projeto.
3. Execute:

```bash
python main.py
```

4. Acesse no navegador:

```text
http://127.0.0.1:5000/
```

## Funcionalidades

- Página inicial acessível via rota `/`
- Estrutura mínima de aplicação web em Flask
- Base para expansão com mais páginas, imagens e interações

## Objetivo

O objetivo deste projeto é servir como base para aprender desenvolvimento web em Python, entender o funcionamento do Flask e criar uma interface web inspirada em um painel visual de imagens.
